## Outcome key

| Code | Meaning |
| --- | --- |
| **S** | Success — completed unaided, no wrong turns |
| **SD** | Success with difficulty — completed, but hesitated, backtracked or took a wrong path first |
| **A** | Completed only after an assist from the moderator |
| **F** | Failed or abandoned |

An **error** is any action that moves away from the goal (wrong tab, wrong
control, undoing a correct step). An **assist** is any hint given — record it
honestly, it is data rather than a failure on your part.
